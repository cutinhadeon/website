Before you send stems

Stem Prep Checklist

Cleaner stems mean faster turnaround and a better result. Run through this before uploading.

✓
Export as WAV, 24-bit
Same sample rate as your session. No MP3s or compressed formats.
✓
Align every stem to the same start point
Bounce from bar 1 with no trimmed silence, so everything lines up automatically on import.
✓
No processing on the master bus
Remove any limiter, EQ, or compression on the main output. Send stems dry, before that stage.
✓
Leave headroom
Peaks around -6dB on individual stems. Nothing should be clipping.
✓
Label files clearly
Kick, bass, lead, perc, vocal, etc. Not "Track 1," "Track 2."
✓
Include a rough mix and BPM/key
A reference bounce of how you imagined it, plus tempo and key, saves a lot of back and forth.
✓
Send via a file transfer link
WeTransfer, Google Drive, or Dropbox. Drop the link in the form below.
